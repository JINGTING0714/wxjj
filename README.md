# wxjj · PRISM — Midjourney 私人资产库

wxjj · PRISM 是一套本地优先的 Midjourney 资产管理与图片处理工作台，用来管理提示词、Profile、Moodboard、搭配配方、日常刷图、水印和拼图批次。

分享地址：<https://jingting0714.github.io/wxjj/>。不需要 GPT / GitHub 登录。每个设备与浏览器保存独立数据，没有共享的资料库。

## 已实现

- 提示词、Profile、Moodboard、水印与图片库均可自由创建、重命名、编辑和删除分类；删除分类不会删除内容。
- 例图支持多张，点击图片可放大、缩放与切换；只在编辑表单中追加例图。资产记录包含来源、作者、获得方式、备注和不限数量的自定义字段。
- 提示词默认整段遮蔽；Profile / Moodboard 短码默认最多显示前三位，长码完整隐藏。编辑时敏感字段也默认隐藏；短码长度不做硬性限制，超过 7 位只提醒核对。Profile 复制为可直接使用的 `--profile 短码`。
- Profile 是文件夹：共用一个长码，内含任意数量的阶段 P / 成品 P / 其他 / 待确认短码。每个短码都有自己的例图、性质、备注和自定义字段；配方引用具体短码而不是随新成品自动替换。
- 批量导入 XLSX / XLSM（含常见 WPS 嵌入图）、DOCX、CSV / TSV、TXT / Markdown、JSON、HTML、文字版 PDF，以及文档与图片 ZIP。一个文件一个库；按作者列 / 工作表辅助识别作者，保留原文件来源和未知列。先预览校对再原子入库；不能确定的例图保留待分配，不凭空推断作者或授权。扫描 PDF 不含 OCR，复杂排版需校对，旧 XLS / DOC 请另存为新版格式。
- 全局搜索和库内搜索，可检索名称、作者、来源、标签与备注，不用暴露密钥。
- 配方编辑器可混合使用库中多选与手填的 Profile / Moodboard，不限数量，支持独立分类、例图、备注与自定义字段。
- 自由图片图库支持批量上传、重命名、移动、删除、发送到拼图区和整库 ZIP 下载；图片只保存在使用者自己的浏览器中。
- 水印库可独立分类和编辑；工坊新上传的水印会自动归档。
- 图片水印最多 5 个独立批次、每批 200 张，以第一张原图为样本。图层可拖动、裁切、缩放、旋转、调透明度与层级；按批次分区检查并可自动送入拼图、标记不合格后重新调整重打。水印 DOM 变换不在每次拖动重新加载图片。
- 独立视频水印区最多 10 个视频，首帧为样本，按原始分辨率与帧时间在本地重新编码并保留音轨。普通画面优先 MP4，透明画面使用 WebM；不是原文件无损复制。引擎由本站加载（首次约 32 MB），不上传视频，每个视频最多 512 MB。
- 拼图批处理最多 1000 张，支持常规比例或 320–8000 px 精确自定义画布、常规宫格或自定义行列、自由起始编号与编号位置/字号/颜色/字重/底板/透明度，以及 JPG/PNG。
- 自定义行列与尺寸即时更新真实预览；可在预览中选择、拖动排序、移除图片，或按全局序号跨板移动，也可打乱所有已导入图片（不按水印批次分组）。拼图完成后自动创建当天的“年月日 拼图”图库，并可一键下载当日全部成品。
- 可安装为 PWA；首次加载后可离线打开。

## 隐私与安全

本项目没有 GPT 登录、账号系统、云端数据库、广告、分析或遥测。公开站点只托管应用代码；程序不会把提示词、Profile、Moodboard、图片、水印或处理结果发送到服务器。每个使用者只能看到自己当前浏览器设备里的本地数据。

使用者在本机创建保险库密码后，PRISM 使用 PBKDF2-SHA-256（310,000 次迭代）派生包装密钥，包装随机数据密钥，并以 AES-256-GCM 加密结构化资产与二进制文件。解锁密钥只保留在当前页面内存中。离线完整备份包含全部加密记录、原文件、例图、工坊设置、输入队列和已生成输出；正在编辑的表单需先保存。

新版 `.prism` 用 ZIP 保存二进制密文和校验清单，导出逐项解密检查，导入先验证密码与所有内容，成功后在一个数据库事务内完整替换。支持旧 v1 JSON 备份；错误密码、结构损坏、混入其他保险库密文的备份不会覆盖目标数据。导入使用原备份密码，不是目标设备的旧密码。没有代码能修复丢失的加密密钥；已有混钥的旧数据应回原设备核对，不要删除原件。

恢复密钥必须在仍能解锁时生成、单独保存。可用它重设密码而不丢资料；密码和恢复密钥同时遗失无法恢复，没有邮箱找回或服务器后门。更换网址属于新的本地存储空间，请在原网址导出、在新网址导入并核对后再处理旧资料。清空浏览器网站数据、无痕模式、浏览器自动回收存储可能丢失本地数据，因此必须定期导出到其他安全位置。托管商仍可能记录普通页面访问日志；应用不上传资产、不部署遥测。

浏览器关闭后无法继续执行运算；同一页切换工作区不停止队列。导出备份 / 锁定会暂停，已经保存的队列可在重新解锁后继续。视频由独立本机线程编码，不依赖前台实时播放，但系统休眠或冻结标签页仍可能暂停。规模上限不代表任意文件体积都能装入设备内存；请保留足够本地空间。国内网络能否直连取决于托管域名、运营商与地区，不能保证所有网络免 VPN；首次成功加载后支持离线使用（视频引擎也需先加载）。若要稳定的国内域名托管，需另有可用域名和相应备案 / 主机安排。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建发布版本：

```bash
npm run build
```

GitHub Pages 的纯静态版本使用相同 React 页面与本地加密逻辑（无服务器接口）：

```bash
npm test
npm run build:pages
```

产物是 `dist/pages`，仓库的 Publish wxjj 工作流自动发布。Sites 的原有构建与发布路径保留。开发者不要把用户备份、恢复密钥或工作坊测试输出提交到仓库。
