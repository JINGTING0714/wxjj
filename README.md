# wxjj · PRISM — Midjourney 私人资产库

wxjj · PRISM 是一套本地优先的 Midjourney 资产管理与图片处理工作台，用来管理提示词、Profile、Moodboard、搭配配方、日常刷图、水印和拼图批次。

公开地址：<https://wxjj.woxiangyyyy.chatgpt.site>

## 已实现

- 提示词、Profile、Moodboard、水印与图片库均可自由创建、重命名、编辑和删除分类；删除分类不会删除内容。
- 例图支持多张并可直接点击追加；资产记录包含来源、作者、获得方式、备注和不限数量的自定义字段。
- 提示词默认整段遮蔽；7 位 Profile / Moodboard 阶段短码默认只显示前三位；Profile 另有默认隐藏的长码/文件夹码。
- 全局搜索和库内搜索，可检索名称、作者、来源、标签与备注，不用暴露密钥。
- 配方编辑器直接读取 Profile / Moodboard 管理库，并允许任意数量的多选组合、例图、备注与自定义字段。
- 自由图片图库支持批量上传、重命名、移动、删除、发送到拼图区和整库 ZIP 下载；图片只保存在使用者自己的浏览器中。
- 水印库可独立分类和编辑；工坊新上传的水印会自动归档。
- 多层水印流水线以第一张原图为样本，每层均可拖动、裁切、缩放、旋转、调透明度和调整层级；一次设定复用于整批，支持合格/重打分流。
- 拼图批处理最多 1000 张，支持常规比例或 320–8000 px 精确自定义画布、常规宫格或自定义行列、自由起始编号与编号位置/字号/颜色/字重/底板/透明度，以及 JPG/PNG。
- 拼图完成后自动创建当天的“年月日 拼图”图库，并可一键下载当日全部成品。
- 可安装为 PWA；首次加载后可离线打开。

## 隐私与安全

本项目没有 GPT 登录、账号系统、云端数据库、广告、分析或遥测。公开站点只托管应用代码；程序不会把提示词、Profile、Moodboard、图片、水印或处理结果发送到服务器。每个使用者只能看到自己当前浏览器设备里的本地数据。

使用者在本机创建保险库密码后，PRISM 使用 PBKDF2-SHA-256（310,000 次迭代）派生密钥，并以 AES-256-GCM 加密结构化资产与图片。密钥只保留在当前浏览器会话的内存中。离线备份导出的仍是密文。

浏览器关闭后无法继续执行图片运算；同一页面内切换工作区不会中断队列。若需要真正的关窗后台处理，应在下一阶段把同一前端封装成 Tauri 桌面应用。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建发布版本：

```bash
npm run build
```
