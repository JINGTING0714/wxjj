# PRISM — Midjourney 私人资产库

PRISM 是一套本地优先的 Midjourney 资产管理与图片处理工作台，用来管理提示词、Profile、Moodboard、搭配配方、日常刷图、水印和拼图批次。

## 已实现

- 提示词、Profile、Moodboard 三类资产库，可自由创建与删除分类；删除分类不会删除内容。
- 例图、机密内容与来源、私人备注三栏式资产记录。
- 提示词默认整段遮蔽；7 位 Profile / Moodboard 默认只显示前三位。
- 全局搜索和库内搜索，可检索名称、作者、来源、标签与备注，不用暴露密钥。
- Profile × Moodboard 搭配配方库与多图结果预览。
- 自由图片图库；图片只保存在使用者自己的浏览器中。
- 多层水印流水线，支持全屏水印、九宫位置、大小与透明度设置、合格/重打分流。
- 拼图批处理最多 1000 张，支持常规与自定义画幅、常规与自定义宫格、起始编号及 JPG/PNG。
- 拼图完成后自动创建当天的“年月日 拼图”图库。
- 可安装为 PWA；首次加载后可离线打开。

## 隐私与安全

本项目没有账号系统、云端数据库、广告、分析或遥测。程序不会把提示词、代码、图片或处理结果发送到服务器。

使用者在本机创建保险库密码后，PRISM 使用 PBKDF2-SHA-256（310,000 次迭代）派生密钥，并以 AES-256-GCM 加密结构化资产与图片。密钥只保留在当前浏览器会话的内存中。离线备份导出的仍是密文。

浏览器关闭后无法继续执行图片运算；同一页面内切换工作区不会中断队列。若需要真正的关窗后台处理，应在下一阶段把同一前端封装成 Tauri 桌面应用。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建发布版本：

```bash
npm run build
```
